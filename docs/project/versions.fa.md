## نسخه‌ها

کتابخانه جوان است: **آلفا**، `0.x`، و API آن ممکن است پیش از `1.0` تغییر کند. نسخه‌ای
که چیزی را که نسخه‌ی قبلی انجام می‌داد، طوری که پروژه متوجه شود، تغییر دهد یک نسخه‌ی
minor تازه است - `0.1` به `0.2` - و [changelog](../changelog.md) هر تغییر این‌چنینی را
با **Changed** علامت می‌زند، با اینکه چه باید کرد.

## به‌روز کردن

```bash
pip install --upgrade django-clearance
python manage.py migrate
python manage.py check
python manage.py clearance_check
```

`migrate` هر مجوزی را که نسخه‌ی تازه اضافه می‌کند می‌سازد - که تا داده نشود هیچ کس آن
را ندارد. `check` و `clearance_check` می‌گویند نسخه‌ی تازه چه چیزی را اشتباه پیدا
می‌کند.
